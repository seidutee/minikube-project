Fix: Escape the Subject Properly (Git Bash)

Run this EXACT command:

openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout tls.key \
-out tls.crt \
-subj "//CN=zay.local/O=kids"


👉 The double slash prevents Git Bash from rewriting the path.

✅ Confirm Files Were Created

Run:

ls


You should see:

tls.key
tls.crt

✅ Now Create the Kubernetes TLS Secret
kubectl create secret tls zay-tls \
  --key tls.key \
  --cert tls.crt \
  -n zayapp


You should get:

secret/zay-tls created

✅ Next — Update Your Ingress To Use TLS

Example:

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: zay-ingress
  namespace: zayapp
spec:
  tls:
  - hosts:
    - zay.local
    secretName: zay-tls

  rules:
  - host: zay.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: web-app
            port:
              number: 80

✅ Apply It
kubectl apply -f ingress.yaml

✅ Add Local DNS Entry

Since you don’t have a real domain, your devices must resolve:

zay.local → Minikube IP


First get Minikube IP:

minikube ip


Example result:

192.168.49.2

✅ Add To Hosts File
On your PC

Edit:

C:\Windows\System32\drivers\etc\hosts


Add:

192.168.49.2 zay.local

On kids’ phones (same Wi-Fi)

Phones don’t allow editing hosts easily.

Instead:

👉 Use your PC as hotspot
OR
👉 Configure router DNS (advanced but better)

For demo → hotspot is easiest.
